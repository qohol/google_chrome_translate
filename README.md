# Chrome Built-in AI 翻訳ツール

Google Chrome（およびChromium系ブラウザ）の組み込みAI機能（Translator API）を利用した、ローカル完結型のリアルタイム翻訳ツールです。  
外部のAPIキー（Google Cloud Translation API等）を必要とせず、ブラウザ内のモデルで安全・高速に翻訳を行うことができます。

---

## 🌟 主な特徴

- **完全ローカル処理**: テキストデータを外部のサードパーティサーバーに送信することなく、ブラウザ内で翻訳が完了します。
- **改行・長文対応**: テキストを改行単位で処理し、リアルタイムで出力結果を更新します。
- **主要言語に対応**: 英語（en）、日本語（ja）、中国語（zh）間の相互翻訳に対応しています。
- **安全設計**: 非対応ブラウザやAPIが無効な環境では明確な警告を表示し、誤動作を防ぎます。

---

## ⚙️ 動作要件・事前準備

このツールを使用するには、**Chrome Built-in AI (Translator API)** に対応したブラウザが必要です。

### 1. 推奨ブラウザ
- **Google Chrome** (Dev / Canary / 最新の安定版)
- **Brave** や **Microsoft Edge** などの Chromium 系ブラウザ (※Built-in AI フラグ対応版)

### 2. Chromeのフラグ設定手順
APIを利用可能にするため、ブラウザで以下の設定を行ってください。

1. アドレスバーに `chrome://flags/#translation-api` を入力して開きます。
2. **Experimental Translation API** を `Enabled` に変更します。
3. ブラウザを再起動（Relaunch）します。

> **注意**: 初めて特定の言語ペアを実行する際、ブラウザがバックグラウンドで言語モデル（数MB〜数十MB）を自動ダウンロードします。ダウンロード中（ステータスバーに進捗が表示されます）は翻訳開始まで少し時間がかかる場合があります。

## 🚀 使い方

1. リポジトリをクローンまたはZIPダウンロードします。
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. `index.html` をお使いのブラウザで開きます。（Webサーバーは不要です）
3. 「入力言語」と「出力言語」を選択します。
4. 原文テキストを入力し、`Ctrl + Enter` キーを押すか「翻訳実行」ボタンをクリックします。
